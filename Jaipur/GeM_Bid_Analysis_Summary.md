### Indian Railways Specific Rules
- Extension with **mutual consent**
- Right to recover LD for loss/inconvenience
- Failure of supply: Contract cancellation + security deposit forfeiture
- Fresh tender may be floated

### How to Request Extension on GeM
1. Login to GeM Seller Dashboard → Orders → Request Extension
2. Upload supporting documents with reason
3. Buyer (DYCMM1 HQ Jaipur / FA&CAO/C HQ JP) reviews
4. If approved: extension granted with/without LD
5. If rejected: LD applies or contract at risk
